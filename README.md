# Ossoma House — Corporate Landing Page

Official corporate landing page for **Ossoma House** (Guest House, Lounge Bar, Restaurant & Spa), located in Talatona, Luanda. 

This project serves as the brand's primary digital front-end, designed to provide a seamless and premium user experience for guests and clients.

## Tech Stack

- **HTML5** — Semantic and accessible markup.
- **Tailwind CSS** (CDN) — 100% utility-first styling for rapid, consistent, and responsive design.
- **Vanilla JavaScript** — Lightweight, dependency-free interactivity for high performance.
- **Bootstrap Icons** — Standardized vector iconography.

## Core Features

- **Responsive Sticky Header** with animated mobile navigation.
- **Hero Fade Slider** — Showcases the property's atmosphere with smooth transitions and dot navigation.
- **Dynamic Content System** — Interactive sidebar for desktop and fullscreen modals for mobile, providing a rich browsing experience.
- **Business Sections** — Dedicated modules for Accommodation, Restaurant (Daily Menu), and Lounge Bar & Spa.
- **Smart WhatsApp Booking System** — Automatically generates a pre-filled `wa.me` link based on user input, streamlining the reservation process.
- **Embedded Google Maps** — Direct location integration.
- **Corporate Brand Identity** — Custom color palette reflecting the brand's warmth and sophistication.

## Brand Design System

The interface is meticulously styled to align with the brand's identity:
- **Dark Green (`#14532D`)** — Core brand color for navigation and action buttons.
- **Gold (`#FFD666`)** — Reserved for premium details, pricing, and highlight elements.
- **Brown/Cream (`#D6C0A3`)** — Used for subtle backgrounds and elegant textures.
